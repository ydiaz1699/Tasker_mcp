# Legacy UI Interaction Tree

This file maps every screen, tab, button, menu, and dialog a Tasker user can reach by tapping or long-pressing inside the legacy interface. The map is built from the labels Tasker actually shows in the app. Read this when you need to tell a user "where is X" or "how do I get to Y".

The map is split into two parts:

1. **Prose intro.** What a new user sees on first launch, the four tabs of the main screen, the floating `+` button, the overflow menu, the project drawer, the long-press pattern, and a typical first-time flow.
2. **Interaction tree.** A hierarchical text map of taps, long-presses, and menu items, organised by entry point.

# Part 1. The first thing a new user sees

When you open Tasker the first thing on screen is a single Activity called the main screen. The name across the top is just "Tasker". Below the title bar are four tabs:

- Profiles
- Tasks
- Scenes
- Vars

The selected tab fills the body of the screen with a list of items of that type. New users land on Profiles by default and see an empty list.

At the bottom-right corner of the screen there is a circular floating button with a plus icon. This is the main "add" control. **The `+` button does a different thing depending on which tab is showing.** This is the single most common point of confusion for new users.

- On the Profiles tab, the `+` button opens a small picker that asks "what kind of trigger do you want": Application, Time, Day, Location, State, or Event. You pick one, configure it, then Tasker asks which task to run when the trigger fires.
- On the Tasks tab, the `+` button asks for a name for a new Task, then opens the Task editor (which is empty until you add Actions to it).
- On the Scenes tab, the `+` button asks for a name for a new Scene, then opens the Scene editor (which starts as a blank canvas).
- On the Vars tab, the `+` button asks for a name for a new Variable. The name must start with `%` and the first letter after `%` must be uppercase if you want the Variable to be global (visible to every task).

A long-press on the `+` button opens the AI Automation Generator (a separate screen that lets you describe what you want in plain language and have Tasker draft a Profile, Task, or Project for you).

In the title bar at the top-right is the overflow menu (the three-dot icon). It is the same on every tab. It contains the global commands: TaskerNet, Tutorials/Pre-made Projects, Disable Tasker / Enable Tasker (one or the other depending on the current state), Preferences, Monitoring, Data, Info, More, Search Tasker, and Report Issue To Developer. Some of those are submenus that open further menus when tapped. The full layout of the overflow menu is in the tree below.

At the bottom of the screen is the **project drawer**. It is a horizontal strip of project tabs. New installs start with a single project called "Base", marked with a home icon. You cannot delete or rename Base. As you add projects they appear to the right of Base in the drawer. Tap a project to switch the four tabs above to show only the contents of that project. Long-press a project (or tap an already-selected project) to open the project options menu (add, delete, export, rename, lock, import, set icon, shift left, shift right, properties, select project).

The four tabs above the list (Profiles, Tasks, Scenes, Vars) are also long-pressable. Long-pressing the Profiles, Tasks, or Scenes tab opens a small menu with "Set Sort" and an import option for that entity type. Long-pressing the Vars tab opens a menu with "Clear All" and "Filter".

To **edit** an item (profile, task, scene, variable) you tap the corresponding tab and then tap the item. Tapping a profile expands it to show its Enter Task, Exit Task, and context icons; tapping the profile name again collapses the row. When a profile is collapsed those targets are not on screen, so any instruction that says "long-press the Enter Task" or "long-press a context icon" first requires tapping the profile name to expand the row. A user setting called Profile Auto-Collapse Mania can auto-collapse profiles after a delay, so do not assume a profile that was expanded a minute ago is still expanded now. Tapping a task opens the Task editor; tapping a scene opens the Scene editor; tapping a variable opens a popup to edit the variable's value.

To **delete, rename, clone, lock, disable, or export** an item, long-press it. A contextual action bar slides in at the top of the screen with the available commands as icons or text (Delete, Rename, Clone, Lock, Disable, Properties, Export, etc.). Tap the icons to act on the selection. Tap items to add more to the selection. The contextual bar exits when you tap its back arrow or press the device Back button.

The typical first-time flow:

1. Tap the `+` button on Profiles.
2. Pick a context type (Application, Time, Day, Location, State, or Event).
3. Configure that context (pick an app, a time range, days of the week, etc.). Tap the device Back button or the bar's accept icon to save the context.
4. Tasker pops up a task picker. Pick "New Task" at the top of the list, give the task a name (or leave it blank for an anonymous task), and the Task editor opens.
5. Inside the Task editor tap the `+` button at the bottom to add the first Action. Pick a category, then an action inside that category, then fill in the action's fields. Tap the accept icon at the top-left to save the action.
6. Repeat to add more actions, or tap the accept icon at the top-left of the Task editor to save the task and return to the profile list.
7. Tasker now shows the new profile with the trigger on the left and the linked task on the right. The profile is on by default.

# Settings reference: what each preference does

The tree above shows where each preference lives. The list below pairs each preference with what enabling / setting it actually does, plus the available options for dropdown settings. Use this when a user asks "what does this setting do?" or "what options does it have?" instead of describing only its location. Sentences here are short on purpose. Quote them or paraphrase as needed.

## UI tab

### UI Lock section

- **Lock Code** (text). Optional code that locks parts of Tasker. Once set, the code is requested when deleting a locked profile, viewing the source of a locked profile or task, or opening the Preferences screen.
- **Lock On Startup** (checkbox). If on, the lock code is asked for as soon as Tasker's UI opens, not only when a locked item is touched.
- **Icon Colour From Theme** (checkbox). Built-in Tasker icons take their colour from the active UI theme. When the icon is shown outside the UI (notifications, widgets) the theme colour is still used.

### Localization section

- **Language** (dropdown). Sets the language of the Tasker UI. Options come from the installed language packs and "System Default".
- **Download Language Pack** (button). Downloads an extra language file. Useful if your language is not bundled with the app.

### Main Screen section

- **Theme** (dropdown). Picks the overall UI colour theme. Available themes are listed in the dropdown.
- **Accent** (colour swatch). Picks the accent colour layered on top of the theme.
- **Orientation** (dropdown). Forces Tasker's UI to a chosen orientation. Options: User (follow the device), Portrait, Landscape.
- **Hide Status Bar** (dropdown). Controls whether Tasker hides the Android status bar inside its own UI. Options: Never, When Editing Scenes, When In Landscape Orientation, Always.
- **List Item Dragging** (dropdown). Controls how rows on the Profiles / Tasks / Scenes / Vars tabs are reordered. Options include dragging by long-press and dragging via a menu entry; pick whichever matches your habit.
- **Animations** (checkbox). Turns Tasker's own UI animations on or off.
- **Haptic Feedback** (checkbox). Enables short vibrations on taps inside Tasker.
- **Hardware Acceleration** (checkbox). Off saves memory and the UI is a fraction slower with some decorations missing; on is faster and prettier.
- **Tips** (checkbox). Shows inline tip popups while you use Tasker. Turn off if you find them noisy.
- **Always Show Enable Icon** (checkbox). Always shows the enable / disable icon at the end of every profile row in the Profiles list, even when the row would normally hide it.

### Profile List Control section

- **Name Text Size** (slider). Font size used for profile, task, scene, and variable names in the main list.
- **Profile Auto-Collapse Mania** (slider). How aggressively Tasker auto-collapses profiles on the Profiles tab, from never to always. Excludes profiles that are currently active; you can still tap to expand or collapse by hand.
- **Ask For New Profile Name** (checkbox). If on, Tasker asks for a profile name as soon as you start creating one. If off, profiles stay anonymous until you name them later.

### General section

- **Confirm Profile Deletes** (checkbox). Shows a confirmation dialog before deleting a profile.
- **Confirm Other Deletes** (checkbox). Same confirmation for non-profile items (tasks, actions inside tasks, contexts, scenes, variables).

## Monitor tab

### General Monitoring section

- **Run In Foreground** (checkbox). Runs Tasker's monitor service in the Android foreground. When on, Tasker is far less likely to be killed by the system but its notification icon is permanent. When off, Android may kill the service to save power, breaking profiles.
- **Show Notification Icon** (checkbox). Permanently shows Tasker's icon in the status bar while Tasker is enabled. Some Android versions only allow notifications to be hidden if the icon is shown here.
- **Show Notification Icon (No Active Profiles)** (checkbox). Same as above, but only while no profiles are currently active. Useful for keeping the icon visible only when something is actually running.
- **Notification Icon** (icon picker). The icon shown in the status bar when the monitor service runs in foreground. Tap to choose another.
- **Custom Notification Layout** (dropdown). Whether to customise Tasker's monitor notification and which text colour to use. Options: None, Black Text, Dark Gray Text, Light Gray Text, White Text, Red Text, Orange Text, Green Text, Blue Text, Black Title Grey Text.
- **Notification Action Buttons** (three task pickers). Up to three tasks can be wired to the buttons inside Tasker's monitor notification, so you can run them from the pull-down.
- **Use Reliable Alarms** (checkbox). Tasker schedules a real system alarm to keep time-based triggers firing on time, including when the phone is asleep. Helps prevent the system killing Tasker to save power. The trade-off is that the alarm becomes visible in the status bar (and may show on the lock screen as a scheduled alarm a few minutes ahead).

### Display On Monitoring section

These set how often Tasker checks each sensor / signal while the screen is on. Smaller numbers respond faster but use more battery. Larger numbers save battery but may delay profile activation.

- **Application Check method** (dropdown). How Tasker detects which app is in the foreground. Options vary by Android version; the dropdown lists what your device supports. If the App context misbehaves, try the other method.
- **Application Check MilliSeconds** (text). Milliseconds between application-foreground checks while the screen is on. Default values work for most users; lower this only if app contexts feel slow.
- **Network Location Check Seconds** (text). Seconds between Network Location fixes used by Location contexts. Lower = more accurate; higher = less battery.
- **GPS Check Seconds** (text). Same as above for GPS fixes.
- **GPS Timeout Seconds** (text). How long Tasker keeps GPS on waiting for a fix before giving up, if Android has not already turned it off. Screen-on only.
- **Wifi Scan Seconds** (text). Seconds between Wi-Fi scans when a "Wifi Near" state is in use.
- **Wifi Timeout Seconds** (text). Minimum seconds before Wi-Fi scanning is stopped after a successful detection. Tasker adjusts dynamically inside this minimum.
- **BT Scan Seconds** (text). Seconds between Bluetooth scans when a "BT Near" state is in use.
- **BT Minimum Timeout Seconds** (text). Minimum seconds before Bluetooth scanning is stopped, similar to Wi-Fi.
- **Cell Workaround** (checkbox). For Cell Near state only. Enables a workaround for an Android bug where cell tower updates are not received. Enable only if Cell Near has stopped firing.

### Display Off Monitoring section

These take over while the screen is off and Android is in deep sleep. Numbers here can usually be larger than their Display-On counterparts.

- **All Checks Seconds** (text). Seconds between every kind of check (apps, locations, scans) while the screen is off. One value covers everything.
- **Timeout Seconds** (text). Maximum seconds Tasker spends on any one check pass while the screen is off. Stops the device from staying half-awake too long.
- **Net/Cell Wake Screen** (checkbox). Briefly turns the screen on (dimly) when Tasker needs to check Cell Near or Network Location. Some devices block these checks unless the screen is on; enable if those contexts misfire at night.
- **Per-sensor "When Off" dropdowns** (Proximity, Light, Magnetic, Pressure, Step, Temperature, Humidity, Accelerometer). Whether Tasker keeps that sensor active while the screen is off, and how. Options depend on the sensor; common choices are No (never), Yes (always), and Yes If Used (only while a profile actively reads it). Affects the matching state (e.g. Light Level state) and the matching built-in variable (e.g. %LIGHT). The Accelerometer dropdown also affects the Gesture and Shake events.

### Accelerometer section

- **Orientation State Accuracy** (dropdown). How close to the specified orientation the device must be for an Orientation state to count as active. Higher = stricter, lower = more lenient.
- **Gesture Initial Sample Rate** (text). Rate (in ms) at which the device position is read before any gesture is partially matched. Saves power between gestures.
- **Gesture Match Radius** (text). How close a live motion must be to the recorded gesture pattern to count as a match. Too low = misses; too high = false positives.
- **Gesture Match Reset Time** (text). After a partial gesture match, the number of milliseconds without further progress before the match resets. Lower = stricter, higher = more forgiving.
- **Calibrate Accelerometer** (button). Recalibrates the accelerometer baseline. Useful when readings drift on a specific device.

### Debugging section

- **Popup Errors/Warnings** (checkbox). Flashes warning and error messages on screen when they occur. Not all warnings produce a popup.
- **Debug To System Log** (checkbox). Sends debugging messages to the Android system log when an action runs or an event is received. The verbosity is high; turn off after debugging.
- **Debug To Internal Storage** (checkbox). Writes debugging messages to `Tasker/log/tasker.txt` on internal storage. Uses extra power and storage; turn off when not debugging.
- **ADB Wifi Logcat** (checkbox, only on supported Android versions). Lets Tasker monitor logcat via ADB Wifi instead of triggering the system permission popup every time on Android 13 and newer.
- **Keep Accessibility Service Running** (button). Picks accessibility services Tasker should try to keep alive if Android kills them. Requires the WRITE_SECURE_SETTINGS permission, granted once via ADB or Shizuku; can also be controlled from a task via the Accessibility Service action.
- **Use Motion Detection** (checkbox). Reduces power usage while the device is still and speeds up the reaction when it starts moving. Does not work well with BT Near for moving devices, with Wifi/BT Near when the AP or device is being switched on/off, or with GPS location radii under a few tens of metres.

## Action tab

- **Quick Settings Tasks** (three task pickers). Tasks bound to the three Tasker tiles in the Android Quick Settings pull-down. Pick a task per tile.
- **App Shortcut Tasks** (three task pickers). Tasks bound to the three launcher app shortcuts (long-press the Tasker icon).
- **Camera Delay** (text). Milliseconds between starting a camera preview and actually taking the photo. Gives auto-focus time. Has no effect on Photo actions in burst sequence mode.
- **Maximum Tasks Queued** (slider). Maximum tasks that can be waiting to run at the same time. New tasks beyond this are ignored.
- **Reset Action Error Notifications** (button). Clears Tasker's "do not show me this error again" memory so suppressed action errors will flash again.
- **Encryption Algorithm** (dropdown). Algorithm used to derive a key from a passphrase and encrypt data with the Encrypt File / Encrypt Text actions. The list reflects what your Android version supports.
- **Encryption Iterations** (text). Iteration count for the key-derivation step. Higher = slower setup but more brute-force resistance.

## Misc tab

- **Local Auto-Backup Max Age** (dropdown). How long Tasker keeps local backup copies of your data. Auto-backups are made every time you exit the Tasker UI. Options: No Auto-Backups, 12 Hours, 1 Day, 2 Days, 1 Week, 2 Weeks, 1 Month, 2 Months, 6 Months.
- **Google Drive Backup** (checkbox). Automatically backs up your Tasker data to Google Drive each time it changes. Waits until the device is charging and on Wi-Fi.
- **New Version Check Frequency** (dropdown, direct distribution only). How often Tasker checks for a new version (only on copies bought outside the Play Store). Options: Never, Every 12 Hours, Every Day, Every 2 Days, Every Week, Every 2 Weeks, Every Month, Every 2 Months, Every 6 Months.
- **Allow External Access** (checkbox). Lets other apps on the device run existing tasks in your Tasker configuration and query Tasker state. Required for some integrations; leave off if you do not need it.
- **Always View Help Online** (checkbox). When on, opening Tasker's help links always uses the online userguide instead of the offline copy bundled with the app.
- **Reduce Resource Usage** (checkbox). Asks Tasker to back off on memory and CPU for some features. Usually means a small drop in responsiveness or feature richness; enable on low-memory devices.
- **Use External Storage** (checkbox). When exporting a project to an APK ("App Factory"-style export), uses external storage instead of internal. Slower but uses less RAM on tight devices.
- **Use New Cell API** (checkbox, only on Android versions that need it). Switches Tasker to a newer Android cell-detection API. Does not work on every device; only enable if Cell Near misbehaves with the default.
- **Flash Problems** (checkbox). Quickly flashes a brief notice on screen when Tasker hits a problem worth showing. Independent of Popup Errors/Warnings; this is for "something is off" rather than a hard error.

### Other Misc tab toggles (conditional / rarely-shown)

These are also on the Misc tab on most builds but may be hidden on some Android versions or device variants.

- **AI Generation Button Enabled** (checkbox). Shows an AI generation icon on Tasker's main screen so you can open the AI generation flow directly. Even when this is off, you can still get to the AI generation screen by long-pressing the `+` button on the main screen.
- **NFC Detection Enabled** (checkbox). Lets Tasker react to NFC tags when scanned. Turn off if you keep an NFC tag in your phone case and it triggers Tasker by accident.
- **Secondary App Enabled** (checkbox). Adds a "Tasker Secondary" icon to your app drawer. Launching that icon fires the "Secondary App Opened" event, which is useful for remapping things like the double-tap-for-camera shortcut or the Bixby button on Samsung devices.
- **Direct Share Targets Enabled** (checkbox). When on, Share Triggers from your "Received Share" events show up directly as share targets in supported apps. Lets you pick a Share Trigger from the Android share sheet without first picking Tasker and then picking the trigger.
- **Notify Action Errors** (checkbox). When an action ends in error, Tasker posts a notification about it (unless that action has its own error-handling that suppresses it).
- **Advanced Export Options** (checkbox). When on, exporting a profile or task description prompts you with advanced format options. Leave off for the standard one-click export.
- **Compact Exports** (checkbox). Strips non-essential data from XML exports. Smaller files, but you may lose UI-only metadata that helps when reviewing the export by hand.
- **Check Permissions On Save** (checkbox). When you exit Tasker from the main screen, Tasker scans your configuration and warns about any missing permissions for the actions you use.
- **Start Monitor On App Open** (checkbox). The monitor service starts immediately when you first open Tasker after a reboot, rather than waiting for the first time a profile would need it.
- **Accessibility Helps Usage Stats** (checkbox). Lets Tasker's accessibility service also detect the current app even when the App Check Method setting is "Usage Stats". Usually makes app detection faster; turn off only if you see anomalies.
- **Widget / Shortcut Task Priority** (slider / text). Priority used by tasks launched from a widget tap, an app shortcut tap, or a task picker popup. Higher = preempts more other queued tasks. See Tasker's task scheduling page for the priority rules.

# Notes on the tree

- Every label above is the text Tasker displays in English. Translations replace those labels in other languages.
- "+ button (bottom right)" always refers to the floating action button. It is one button; its destination changes per tab.
- "Long-press" means press and hold for roughly half a second.
- On the Profiles tab a profile row can be in a collapsed state. While collapsed, the Enter Task entry, the Exit Task entry, and the context icons on the left of the row are not on screen. Tap the profile name to expand the row; tap it again to collapse. Every per-profile long-press target listed under the Profiles tab branch only works while the profile is expanded. If a user says the Add Exit Task entry, the Context Options popup, or the Task Options popup never appears, the most likely cause is that their profile is collapsed; tell them to tap the profile name first.
- A "contextual action bar at the top" is the temporary toolbar that replaces the title bar when you have one or more list items selected. Tap the back arrow on the left of that bar to exit selection mode.
- Items marked "only in Beginner Mode" or "not in Beginner Mode" depend on the Beginner Mode setting. New installs default to having Beginner Mode off, so most users see every entry.
- Items marked "direct distribution only" are extras for users who bought Tasker outside the Play Store. Play Store users do not see them.
- Items marked "only on Android version X and newer" appear only on Android versions where the underlying capability exists. Tasker hides them on older versions to avoid showing options that cannot work.
- When the FAB on the Profiles tab launches the Add Context picker, picking Location works two different ways: if you have at least one named location already, Tasker first shows the existing locations and only opens the Location editor when you tap "New Location" at the top of that list.
- The Application context picker is multi-select. Picking three apps creates a single Application context that matches when any of those three apps is in the foreground.
- After you configure a context for a brand-new profile and tap Accept, Tasker always prompts for the task. If you cancel the task picker, Tasker offers to delete the unfinished profile rather than leaving a context with no task.
- The Task editor (called "Task Edit" in the title bar) is reached from many places: tapping a task on the Tasks tab, tapping the linked task on the right side of a profile row, picking "New Task" from a task picker, or following an Add Enter Task / Add Exit Task menu entry from a profile.
- The Action editor (called "Action Edit") is reached from tapping any action inside the Task editor or from picking an action from the Action picker.
- The Variable popup is intentionally simple: it is the only way Tasker exposes "set a variable's value by hand from the UI". To rename a variable, long-press it instead.
