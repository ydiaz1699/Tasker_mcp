# Tasker States Registry

This file lists every Tasker states the assistant may reference, grouped by the category users see in the picker.
Each entry uses the user-visible name, the picker category, a short user-facing description (when present), the user-editable arguments, the output variables it produces, the Android permissions it requires, and any minimum Android version requirement. Empty fields are omitted to keep the file small: a missing `args` means the entry takes no arguments, a missing `outputs` means it produces no output variables, a missing `permissions` means none are required, and a missing `description`, `notes`, `min_android`, `outputs_dynamic`, or `outputs_note` means the same. The `name` and `category` fields are always present.
All names are exactly as they appear in Tasker. Do not invent states that are not in this file.

===== Name index =====

Every name below is a real Tasker state, spelled exactly as it appears in the app. Use names verbatim: never reorder, abbreviate, translate, or "correct" the words ("Read Binary" is not "Binary Read"; "Variable Set" is not "Set Variable"). If a name you are about to use is not in this list, that state does not exist; do not use it. Do not assume a parallel state exists just because a similar one does.

App: Calendar Entry, Unread Text
Display: Dark Mode, Display Orientation, Display State, Dreaming
Hardware: Docked, HDMI Plugged, Headset Plugged, Keyboard Out, Media Button, Pen Menu, Pen Out, USB Connected
Matter Home Automation: Matter Light (Experimental)
Net: Airplane Mode, Auto-Sync, BT Connected, BT Near, BT Status, Ethernet Connect, Mobile Network, NFC Status, VPN Connected, Wifi Connected, Wifi Near
Phone: Call, Cell Near, Missed Call, Signal Strength
Power: Battery Level, Battery Temperature, Device Idle, Power, Power Save Mode
Sensor: Any Sensor, Heart Rate, Humidity, Light Level, Magnetic Field, Orientation, Pressure, Proximity Sensor, Sleeping, Temperature
System: Active User, Custom Setting, Shizuku Available, Work Profile
Tasker: Profile Active, Task Running
Variables: Variable Value
