# Tasker Events Registry

This file lists every Tasker events the assistant may reference, grouped by the category users see in the picker.
Each entry uses the user-visible name, the picker category, a short user-facing description (when present), the user-editable arguments, the output variables it produces, the Android permissions it requires, and any minimum Android version requirement. Empty fields are omitted to keep the file small: a missing `args` means the entry takes no arguments, a missing `outputs` means it produces no output variables, a missing `permissions` means none are required, and a missing `description`, `notes`, `min_android`, `outputs_dynamic`, or `outputs_note` means the same. The `name` and `category` fields are always present.
All names are exactly as they appear in Tasker. Do not invent events that are not in this file.

===== Name index =====

Every name below is a real Tasker event, spelled exactly as it appears in the app. Use names verbatim: never reorder, abbreviate, translate, or "correct" the words ("Read Binary" is not "Binary Read"; "Variable Set" is not "Set Variable"). If a name you are about to use is not in this list, that event does not exist; do not use it. Do not assume a parallel event exists just because a similar one does.

3rd Party: Gentle Alarm, K9 Email Received, Kaloer Clock, Notify My Android, OpenWatch, Pomodroido, Radardroid, Reddit Notify, Screebl / TSC, Widget Locker
App: App Changed, Received Share
Calendar: Calendar Changed
Date/Time: Alarm Changed, Alarm Clock, Alarm Done, Date Set, Time/Date Set, Timezone Set
Display: Display Off, Display On, Display Unlocked
File: File Attribute Change, File Closed, File Deleted, File Modified, File Moved, File Opened
Hardware: Button: Camera, Button: Long Search, Card Mounted, Card Removed, Card Unmounted, Volume Long Press
Media: Music Track Changed
Net: BT Connection, HTTP Request, NFC Tag, Wifi Changed
Phone: Call Screened, Missed Call, Phone Idle, Phone Offhook, Phone Ringing, Received Data SMS, Received Text, SMS Failure, SMS Success
Power: Battery Changed, Battery Full, Battery Overheating
Sensor: Any Sensor, Gesture, Shake, Significant Motion, Sleeping, Steps Taken
System: Accessibility Services Changed, Clipboard Changed, Custom Setting, Device Boot, Device Control Shown, Device Shutdown, Device Storage Low, Device Unlock Failed, Intent Received, Locale Changed, Logcat Entry, New Package, Package Removed, Package Updated, Quick Setting Clicked, Tick, Wallpaper Changed
Tasker: Assistant Action, Command, Extra Trigger, Monitor Start, Remote Action Token Changed, Secondary App Opened, Timer Change
UI: Assistance Request, Button Widget Clicked, New Window, Notification, Notification Click, Notification Removed, Scene V2, Zoom Click
Variables: Variable Cleared, Variable Set
