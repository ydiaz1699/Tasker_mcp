# Documentación de Referencia y Gem de Gemini

Esta carpeta contiene la base de conocimiento y especificaciones originales utilizadas para alimentar el Gem de Gemini ("Tasker Expert"), que sirvió como fundamento para la base de datos de conocimiento (`src/tasker_mcp/knowledge/`) y el motor XML de este servidor MCP.

## Contenido

* `tasker_ai_system_instructions.txt`: Instrucciones de sistema completas para el agente de IA especializado en Tasker (especificación 6.7.6-beta, reglas de sintaxis de acciones, etiquetas `<label>`, anclas y restricciones de formato XML).
* `instrucciones.md`: Prompt de rol y reglas de comportamiento del Gem.
* `01_tasker_fundamentals.txt` a `10_video_resources.txt`: Registros estructurados de acciones, eventos, estados, variables, compatibilidad con plugins y patrones de automatización.
